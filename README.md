# Aica Two Robots

One funny line of awkward small talk that one robot says to another
while they ride an elevator together — recalculating routes, blaming
firmware, and pretending the silence is a feature.

## How it works

- `main.py` (standard library only, deterministic) writes the line to
  `/output/entry.txt`.

Run `python3 main.py` to produce the output file.
